# Shell Configurations

This directory contains shell-agnostic and shell-specific configurations:

- [**`common/`**](file:///Users/me/env-setup-dotfiles/.shell/common): Shared aliases and functions loaded by all shells.
- [**`bash/`**](file:///Users/me/env-setup-dotfiles/.shell/bash): Bash-specific configuration profiles, aliases, completions, and functions.
- [**`zsh/`**](file:///Users/me/env-setup-dotfiles/.shell/zsh): Zsh-specific configuration profiles, aliases, completions, and functions.
- [**`bin/`**](file:///Users/me/env-setup-dotfiles/.shell/bin): Executable scripts added to the system `PATH`.
